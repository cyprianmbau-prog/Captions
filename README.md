Description

This a site is designed with two pages which hold meaningful content to those with a passion in photography.The first page is briefly an introduction to the page containing an image of a western street with people.The second page contains the contributors favourite images, contributors biography and a submit form at the end.The main reason of building this site is to help those who probably love photos and help them veiw their favourite photos with ease.The viewer can add/update his/her phone number and name in the form at the end of the second page then clicking on submit button.This makes the viewer have an advantage of joining the site and enjoying it's benrfits.
